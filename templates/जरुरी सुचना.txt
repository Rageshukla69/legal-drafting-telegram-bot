Agar Apake computer/laptop me Hindi Court Drafts Support 
nahi karte he, toh fir aapko sath me diye gaye sare Hindi Fonts
aapke Computer/Laptop me install karane he.

Agar Fonts Kaise install karna he yeh pata nahi he,
toh fir aap niche click karke video check kar sakte ho -

https://www.youtube.com/watch?v=0o1wNazI1HA



Fonts Install hone ke bad aapko, 
1) Hindi Drafts ki word file open karni he.
2) Open Hone ke bad - "Control + A" type karna he, jisase aapka
drafts sara ek sath select ho jayega.
3) Sara draft select hone ke bad aapko fonts me jakar Mangal Font
select karni he.
4) aur aapke fonts support karne lagenge.
5) Agar fir bhi drafts support nahi karte he, toh fir aapko aapka 
word update karna padega.
